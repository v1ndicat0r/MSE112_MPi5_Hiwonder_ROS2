# Vision Stack
This package contains the image handling and computer vision pipelines required for the MSE112 projects (Currently only project 1 complete)


# Nodes
This package contains 5 nodes that can be run via command line execution:
* image_publisher
* line_tracking
* bin_mask
* line_recog
* edge_recog

## image_publisher
This node is at the core of all cv. It takes the raw camera image input and broadcasts it on the image_topic topic with a period of 10ms.

#### ros Information
This node publishes 1 topic:
* image_topic (Image)

## line_tracking
This node performs the project 1 line tracking operations, outputting a value that represents the x centroid of the detected line. The binary mask used in this operation can be tuned using the configs.json file located in the same directory (using HSV colour space). The target color of the algorithm defaults to 'green' but can be set to 'red' or 'blue' using the target_line_color_topic. This value is stored upon hearing. Operates at the speed of the image_topic.

#### ros Information
This node pis subscribed to 2 topics:
* image_topic (Image)
* target_line_color_topic (String)

This node publishes to 1 topic:
* line_tracking_topic (Int16)

## bin_mask
This node is depricated. This forms the basis for a failed cv pipeline. A binary mask (tuned with configs.json in HSV) is applied for both blue and green and the resulting masks are broadcast on their own topics.

#### ros Information
This node is subscribed to 1 topic:
* image_topic (Image)

This node publishes to 2 topics:
* green_mask (Image)
* blue_mask (Image)

## line_recog
This node is depricated. This node applies the old line tracking algorithm on the blue and green binary masks generated by bin_mask. Each mask is de-noised and skeletonized. Then houghlines is applied and the resultant lines are averaged in x and slope and min-maxed in y. Averages are weighted with detected line length. Outputs the x1,y1,x2,y2 values of the averaged line as an Int16MultiArray representing the 4tuple. Each line overlayed over the binary mask is also pulbished on the visualization topics.

#### ros Information
This node is subscribed to 2 topics:
* green_mask (Image)
* blue_mask (Image)

This node publishes to 4 topics:
* green_line_recog (Int16MultiArray)
* blue_line_recog (Int16MultiArray)
* green_line_recog_visu (Image)
* blue_line_recog_visu (Image)

## edge_recog
This node is depricated and does not perform notable tasks.
